# Temperature Converter

A simple Python temperature converter that allows users to convert between Celsius and Fahrenheit.

## Features

- Basic input error handling
- Uses functions to perform temperature conversions
- Separates reusable functions into a separate Python module
- Uses `if` statements to select the conversion
- Uses f-strings to display the results

## What I Learned

- Working with functions and return values
- Importing and using a separate Python module
- Handling invalid numerical input with `try` and `except`
- Using conditional statements
- Formatting output with f-strings
